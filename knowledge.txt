Q: What do I need to do first as a new user?
K: getting started, new user, how to start, first steps, setup guide, onboarding, before i can use the bot
A: Welcome! Here's the quickest path to using the bot: 1) Go to Main Menu -> 🔑 Set APIs and add your Bybit API Key/Secret (free — no Pro needed). 2) Request an upgrade from Main Menu -> ⬆️ Upgrade Plan if you want price bot, order monitor, auto-pay, and other Pro features. 3) Once you're Pro, open 📊 AD PRICE BOT and set your Ad ID + Bybit UID before starting the price bot. 4) Turn on 📦 Order Monitor so incoming orders are tracked automatically. That's the core setup — everything else (Auto-Pay, Buyer Protection, Name Match) is optional on top of that.

Q: What is the auto price bot and what are the benefits?
K: what is price bot, ad price bot, auto price, price bot benefits, why use price bot
A: The auto price bot keeps your P2P ad price updated automatically instead of you manually editing it every few minutes. You set a mode (Fixed price, or Floating based on a reference price) and an update interval, and the bot reprices your ad for you in the background. Benefits: your ad stays competitive around the clock, you don't lose trades to faster competitors, and you save the time of manually watching and editing prices all day.
---

Q: What is Order Monitor and what are the benefits?
K: what is order monitor, order monitor benefits, why use order monitor
A: Order Monitor watches your incoming P2P buy/sell orders in real time and alerts you the moment a new order comes in, with the order details. Benefits: you never miss an order notification, you can react (pay, release, or flag) faster, and it feeds the bot's other safety features — Buyer Protection, Name Match, and fraud checks — which only run on orders the monitor sees.
---

Q: How does Auto-Pay work?
K: how auto pay works, autopay explained, auto pay, automatic payment, flutterwave pay, paga pay
A: Auto-Pay automatically sends payment to the buyer's bank account the moment you confirm a sell order, instead of you doing a manual bank transfer every time. You choose the payment rail — Bybit balance auto-pay, Flutterwave auto-pay, or Paga auto-pay — and each needs its own API keys set up first under Set APIs. Once enabled from the Auto-Pay section, the bot detects a newly paid sell order, matches the buyer's bank details, and sends the payout automatically — you just get a confirmation message once it's done.
---

Q: How do I set up Buyer Protection?
K: buyer protection setup, how to set up buyer protection, buyer protection threshold, protect buyer, cancel protection
A: Go to Main Menu -> 💳 AUTO-PAY -> Buyer Protection and tap the toggle to turn it on. Then set your threshold in minutes (e.g. 30) — this is how long the bot waits on a slow or suspicious seller cancel request before flagging it to you instead of letting it go through automatically. When it's flagged, you'll get an Accept/Reject prompt so you stay in control instead of losing coins to a rushed cancel.
---

Q: What is Name Match and how do I turn it on?
K: name match, name matching, buyer name check, turn on name match
A: Name Match checks the payer's name on an incoming payment against the name on file for that order — and against the scammer list — before funds are released, catching mismatched or fraudulent payments. Turn it on from Main Menu -> 💳 AUTO-PAY -> Name Match toggle.

Q: How do I find my public IP and set it up on Bybit, Flutterwave, and Paga?
K: get my ip, whitelist ip, get ip, ip address, ip whitelist, set up bybit ip, whitelist bybit, whitelist paga, whitelist flutterwave
A: Go to Main Menu -> 🌍 Get My IP to see the bot's current public IP address. Then whitelist that exact IP on each platform you use: on Bybit, go to API Management -> your API key -> edit and add the IP under IP restriction. On Flutterwave, go to Settings -> API -> Webhooks/IP whitelist and add it there. On Paga, go to your Business dashboard -> Settings -> IP Whitelist and add it. Do this for every service whose API keys you've connected, or those API calls will be rejected.
