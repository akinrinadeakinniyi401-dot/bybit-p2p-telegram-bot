### BYBIT API (FAQ 26-35) ###

Q: How do I connect my Bybit API?
K: how do i connect my bybit api, connect bybit, set bybit api, bybit setup, bybit account
A: Go to API Settings -> Set Bybit Account 1 API (or Account 2). Paste your API Key, then your Secret Key when prompted. Run /pingbybit afterward to confirm the connection works.
---

Q: Where do I get my Bybit API Key and Secret Key?
K: where do i get my api key, where do i get my secret key, bybit api dashboard, create bybit api key
A: On Bybit, go to your account's API Management page and create a new API key there. Bybit will show you the API Key and Secret Key together only once at creation — copy both immediately and paste them into the bot under API Settings.
---

Q: Why is my Bybit API connection failing / my api dey fail?
K: why is my api connection failing, my api dey fail, my bybit api dey fail, bybit connection error, api not working, bybit api fail, my bybit api isnt working, my bybit api is not working, api isnt working what should i do
A: A few common causes: your API Key/Secret was mistyped or copied with extra spaces, the key doesn't have P2P/trading permissions enabled, or your bot's current IP isn't whitelisted on the Bybit API key (use Get My IP to find it and add it under IP restriction on Bybit). Run /pingbybit after fixing to confirm.
---

Q: What permissions should my Bybit API have?
K: what permissions should my api have, bybit api permissions, p2p permission
A: Enable read and trade permissions for P2P/Spot on your Bybit API key — without P2P permission specifically, ad management and order actions will fail even if the key otherwise looks connected.
---

Q: How do I test my Bybit connection / what does /pingbybit do?
K: how do i test my bybit connection, what does pingbybit do, pingbybit
A: Run /pingbybit any time — it checks whether your Bybit API connection is working correctly. Use it right after adding your keys, or whenever something seems off. A successful result means your account is ready for trading.
---

Q: Can I update my Bybit API later, and how do I delete it?
K: can i update my api later, how do i delete my bybit api, change bybit api key, remove bybit api
A: Yes — just go back to API Settings -> Set Bybit Account 1/2 API and enter new values to overwrite the old ones. To remove a saved key entirely, use Delete APIs and select the one you want to delete.
---

### AD PRICE BOT (FAQ 51-76) ###

Q: What is the AD Price Bot and how do I use it?
K: what is the ad price bot, how do i use the ad price bot, ad price bot benefits, why use price bot
A: The AD Price Bot automatically edits your Bybit advertisement price so you don't have to manually update it every few minutes. Setup: 1) My Ads List — fetch every ad linked to your account and copy the Ad ID you want to manage. 2) Set AD ID — paste it in. 3) Fetch AD Details — required before editing can begin. 4) Set Interval — how often it updates (e.g. "3" = every 3 minutes). 5) Choose Fixed Mode or Floating Mode. Then Update Once Now to test, or Start Auto Update to run continuously.
---

Q: Where do I find my Ad ID and how do I use My Ads List?
K: where do i find my ad id, where i see my ad id, my ads list, advertisement id, find ad id
A: Open My Ads List — the bot fetches every advertisement linked to your Bybit account and shows their IDs, with color indicators (🔴 red = currently offline, 🟢 green = currently online/active). Copy the Ad ID you want to manage from there.
---

Q: What is Set AD ID and why do I need Fetch AD Details?
K: what is set ad id, why do i need fetch ad details, fetch ad details required, do i need to fetch my ad before posting
A: Set AD ID is where you paste in the Advertisement ID copied from My Ads List — the bot saves it as the one it will manage. Fetch AD Details then pulls the ad's payment methods, currency, and current settings from Bybit — this step is required before any editing, posting, or price updates can begin.
---

Q: How do I set my Bybit UID in the bot?
K: how do i set my uid, how to set my uid in the bot, set my uid, bybit uid, where do i find my uid
A: Your Bybit UID is the numeric ID on your Bybit P2P profile page (tap your username/avatar on any P2P ad to see it). Set it alongside your Ad ID in the AD Price Bot section — the bot uses it to correctly match incoming orders and buyer/seller details to your account.
---

Q: Why isn't my ad updating / why no dey update my ad?
K: why isnt my ad updating, why no dey update my ad, ad not updating, price bot not working, ad price stuck
A: Common causes: Auto Update hasn't been started yet (tap Start Auto Update), AD Details haven't been fetched (do that first), your Bybit API permissions don't cover P2P ad editing, or (for Floating Mode) your NGN/USDT reference price hasn't been set. Check each of these in order.
---

Q: What is Set Interval and what interval should I use?
K: what is set interval, what interval should i use, ad update interval, how often does ad update
A: Set Interval controls how many minutes pass between each automatic price update — for example "3" means every 3 minutes. Shorter intervals keep your price more competitive but make more API calls; most users run somewhere between 1 and 5 minutes.
---

Q: What is Fixed Mode and Floating Mode, and which coins use them?
K: what is fixed mode, what is floating mode, which coins use fixed mode, which coins use floating mode, fixed vs floating
A: Fixed Mode is best for USDT/USDC — you set an Increment (e.g. "10") and the bot adds ₦10 to the price on every update. Floating Mode is best for BTC/ETH — you set a Float percentage (e.g. "110") plus an NGN/USDT Reference Price copied from the Bybit ad page, and the bot calculates your price off that reference.
---

Q: What is Set Increment and Set Float?
K: what is set increment, what is set float, increment amount, float percentage
A: Set Increment (Fixed Mode) is the fixed amount added to your ad price on every update. Set Float (Floating Mode) is the percentage used to calculate your price relative to the NGN/USDT reference price.
---

Q: What is the NGN/USDT Reference Price and where do I find it?
K: what is the ngn usdt reference price, where do i find the reference price, ngn usdt reference, reference price location
A: It's the current NGN/USDT rate shown on the Bybit advertisement page for the coin you're floating against. Copy that number and paste it into Set NGN/USDT Ref inside the bot — Floating Mode uses it as the base for calculating your ad price.
---

Q: What does Update Once Now and Start Auto Update do, and how do I stop it?
K: what does update once now do, what does start auto update do, how do i stop auto update, stop price bot
A: Update Once Now updates your ad price a single time immediately — good for testing your settings. Start Auto Update runs continuously, editing the ad on the interval you set. To stop it, open the AD Price Bot section and tap the stop/toggle button — it runs until you turn it off.
---

Q: Can I edit or manage multiple ads?
K: can i edit multiple ads, manage multiple ads, several ads at once
A: You manage one Ad ID at a time through Set AD ID — to switch to a different ad, set a new Ad ID and Fetch AD Details again for that one.
---

Q: How do I post my advertisement?
K: how do i post my advertisement, post ad, post advertisement, go online, why cant i post my ad, why can't i post my ad
A: 1) Open My Ads List and copy the Ad ID with the red indicator (offline). 2) Open Post / Remove AD. 3) Click Set Manage AD ID and paste it. 4) Click Fetch Manage AD. 5) Click Post AD (Go Online). If posting fails, make sure you fetched the ad's details first and that your API has P2P permissions.
---

Q: How do I remove my advertisement?
K: how do i remove my advertisement, remove ad, remove advertisement, go offline, why cant i remove my ad
A: 1) Open My Ads List and copy the Ad ID with the green indicator (online). 2) Open Post / Remove AD. 3) Click Set Manage AD ID and paste it. 4) Click Fetch Manage AD. 5) Click Remove AD (Go Offline).
---

Q: Why are some Ad IDs red and others green?
K: why are some ad ids red and others green, red green indicator meaning, ad color meaning
A: The color shows the ad's current status on Bybit: 🔴 red means the ad is currently offline (not live), 🟢 green means it's online and active. Use red ads with Post AD, and green ads with Remove AD.

### AUTO PAY (FAQ 87-96) ###

Q: What is Auto Pay and does it send money?
K: what is auto pay, does auto pay send money, how does auto pay work, bot no dey mark paid, how to use auto pay, how do i use auto pay
A: Auto Pay works together with Order Monitor — when a Buy order is detected, Auto Pay performs whichever actions you've enabled. Enable Auto Pay (Bybit) only marks the order as Paid on Bybit; it does NOT send money by itself. To actually move money automatically you need Flutterwave Pay or Paga Pay enabled, each with its own API set up first. If the bot isn't marking orders paid, check that Order Monitor is running and Auto Pay (Bybit) is toggled on.
---

Q: What is Bybit Auto Pay, Flutterwave Auto Pay, and Paga Auto Pay?
K: what is bybit auto pay, what is flutterwave auto pay, what is paga auto pay
A: Bybit Auto Pay marks Buy orders as Paid on Bybit — no money movement. Flutterwave Auto Pay and Paga Auto Pay each send money from your connected Flutterwave/Paga account automatically once a sell order is confirmed paid. You can also Set Sender Name, shown on Flutterwave transfer remarks.
---

Q: Can Auto Pay work without Order Monitor?
K: can auto pay work without order monitor, does auto pay need order monitor
A: No — Auto Pay relies on Order Monitor to detect new Buy orders in the first place. Make sure Order Monitor / Start Monitoring is running for Auto Pay to do anything.
---

Q: What is Buyer Protection and why was my order blocked by it?
K: what is buyer protection, why was my order blocked by buyer protection, buyer protection threshold, protect buyer, cancel protection, set up buyer protection
A: Buyer Protection protects you from buyers with a long average release time. Set a threshold in minutes — e.g. 15 — and any buyer whose average release time exceeds that gets flagged; Auto Pay won't approve their order automatically. If your order was blocked, it's because that specific buyer's release history crossed your threshold — check View Unpaid Orders to see it and decide manually.
---

Q: What is View Unpaid Orders?
K: what is view unpaid orders, unpaid orders list, blocked orders
A: View Unpaid Orders shows every order that Buyer Protection has blocked from automatic payment, so you can review and handle them manually.
---

Q: What is Buy Volume (24 Hours)?
K: what is buy volume 24 hours, buy volume analytics, how much have i bought, 24 hour volume
A: Buy Volume (24 Hours), inside the Auto Pay section, displays your total Buy volume over the last 24 hours — useful for tracking your own trading activity, resetting automatically every 24 hours.
---
