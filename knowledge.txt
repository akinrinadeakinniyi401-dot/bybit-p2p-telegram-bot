Q: What do I need to do first as a new user?
K: getting started, new user, how to start, first steps, setup guide, onboarding, before i can use the bot, setup progress
A: Open /menu to see your dashboard — it shows your Telegram User ID, current plan, active Bybit account, and a setup progress counter (0/5 to 5/5). To reach 5/5: 1) Set your Bybit API key under API Settings (free). 2) Request an upgrade if you want Pro features. 3) Set your AD ID in the AD Price Bot section. 4) Fetch your AD details. 5) Start Order Monitor. Only one Bybit account (Account 1 or Account 2) can be active at a time.

Q: How do I open the dashboard / what does /menu show?
K: menu, dashboard, home, setup, status, account, what does menu show
A: The /menu command opens the bot dashboard. It shows your Telegram User ID, your current subscription plan, your active Bybit account (Account 1 or Account 2), your setup progress (0/5 to 5/5), and which features are currently active. Only one Bybit account can be active at a time — if you want to switch from Account 1 to Account 2, first stop every active bot service, switch accounts, then start the services again.

Q: How do I switch between Bybit Account 1 and Account 2?
K: switch account, change bybit account, account 1 account 2, switch bybit
A: Only one Bybit account can be active at a time. Before switching: 1) Stop every active bot service (price bot, order monitor, auto-pay, etc). 2) Switch to the other account under API Settings. 3) Start the services again. Switching without stopping services first can cause the bot to mix up orders between accounts.

Q: What is the AD Price Bot and how does it work?
K: what is price bot, ad price bot, auto price, price bot benefits, why use price bot
A: The AD Price Bot automatically edits your Bybit advertisements so you don't have to manually update the price every few minutes. Setup: Step 1 — open My Ads List to fetch every ad linked to your account and copy the Advertisement ID you want to manage. Step 2 — open Set AD ID and paste it in. Step 3 — click Fetch AD Details to pull payment methods, currency, and current settings (required before editing can begin). Step 4 — set your update Interval in minutes (e.g. "3" = every 3 minutes). Step 5 — choose Fixed Mode (best for USDT/USDC, uses Set Increment e.g. ₦10 added each update) or Floating Mode (best for BTC/ETH, uses Set Float percentage plus a Set NGN/USDT Ref price copied from the Bybit ad page). Then use Update Once Now to test it, or Start Auto Update to run it continuously.

Q: How do I set my Ad ID and fetch ad details?
K: set ad id, fetch ad details, my ads list, advertisement id
A: First open My Ads List — the bot fetches every advertisement linked to your account; copy the Advertisement ID you want to manage. Then open Set AD ID and paste it in. Finally click Fetch AD Details to retrieve payment methods, advertisement information, currency, and current settings — this step is required before any editing can begin.
---

Q: What's the difference between Fixed Mode and Floating Mode?
K: fixed mode, floating mode, set increment, set float, ngn usdt reference
A: Fixed Mode is best for USDT/USDC — you use Set Increment (e.g. "10") and the bot adds ₦10 to the ad price on every update. Floating Mode is best for BTC/ETH — Set Increment becomes Set Float, where you enter a floating percentage (e.g. "110"), then click Set NGN/USDT Ref and paste the NGN/USDT reference price copied from the Bybit advertisement page.

Q: What is Order Monitor and what are the benefits?
K: what is order monitor, order monitor benefits, why use order monitor, start monitoring
A: Order Monitor checks your Bybit P2P account every 10 seconds for new orders. Once you tap Start Monitoring, the bot immediately sends you the order details whenever a new order arrives. Benefits: you never miss an order, you react faster, and it powers the bot's other safety features (Buyer Protection, Name Match, fraud checks), which only run on orders the monitor sees.

Q: What is Auto Pay and how does it work?
K: how auto pay works, autopay explained, auto pay, automatic payment
A: Auto Pay works together with Order Monitor — when Order Monitor detects a Buy order, Auto Pay performs whichever actions you've enabled: Enable Auto Pay (Bybit) automatically marks Buy orders as Paid, but this does NOT send money by itself. Enable Flutterwave Pay automatically sends money from your Flutterwave account (requires Flutterwave API set up first). Enable Paga Pay automatically sends money from your Paga Business account (requires Paga API set up first). You can also Set Sender Name, which is the name shown on Flutterwave transfer remarks.
---

Q: Does Bybit Auto Pay actually send money?
K: does auto pay send money, bybit auto pay money, auto pay bybit only
A: No. Enable Auto Pay (Bybit) only marks Buy orders as Paid on Bybit — it does not move any money. To actually send money automatically, you need Flutterwave Pay or Paga Pay enabled, each with its own API configured under API Settings.
---

Q: How do I set up Buyer Protection?
K: buyer protection setup, how to set up buyer protection, buyer protection threshold, protect buyer, cancel protection
A: Buyer Protection protects you from buyers with a long average release time. Set your threshold in minutes — for example, if set to 15 minutes, any buyer whose average release time exceeds 15 minutes will be flagged, and Auto Pay will not approve that order automatically. Use View Unpaid Orders to see every order that Buyer Protection has blocked.

Q: How do I withdraw my referral balance?
K: withdraw, payout, get paid, cash out, referral payment, withdraw balance, withdraw money, withdraw my balance, withdraw my earnings
A: Open Main Menu -> 🎁 Referrals -> 💸 Withdraw. You'll be asked for your bank account number, account name, and bank name, then the amount you want to withdraw — the minimum is ₦5,000. If your available balance is below the amount you request, the withdrawal fails with an insufficient balance message and nothing is deducted. If it's approved to proceed, the amount is deducted from your balance right away and the request goes to Pending Processing. The admin reviews it: if approved, your withdrawal is marked Completed and the money stays deducted (it's on its way to your account); if rejected, the amount is automatically returned to your balance.
